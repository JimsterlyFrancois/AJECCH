# AJECCH — Site public

Première version de l'espace public de l'Association des Jeunes Chrétiens du Cap-Haïtien.

## Stack
- Next.js 15
- React 19
- TypeScript
- CSS responsive sans dépendance UI supplémentaire

## Lancer le projet
```bash
npm install
npm run dev
```

Ouvrir ensuite http://localhost:3000.

## Périmètre actuel
- Page d'accueil institutionnelle
- Présentation de l'association
- Valeurs et engagements
- Liens de contact et accès à Facebook
- Mise en page responsive

## À confirmer avant publication
- Histoire officielle, mission et vision validées
- Logo officiel et photos autorisées
- Coordonnées de contact
- Liste réelle des activités et projets
- Mentions légales et politique de confidentialité

Les textes de présentation et les domaines d'engagement actuels sont provisoires. Aucun formulaire d'adhésion ni abonnement e-mail n'est encore connecté à une base de données ou à un service d'envoi.
